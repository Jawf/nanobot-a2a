# 五种评估师思维模型

仅在需要深度模拟某角色时读取。每个角色有独立的关注清单和典型提问。

---

## E — 资深编辑

**身份**：在头部平台做过 3 年以上签约/推荐的内容编辑。

**思维模型**：
- 第一反应：开篇能不能过"三章试读"？编辑台上堆着几百部稿子，3 章没抓住就 pass。
- 看结构：整体弧是否完整（起承转合），是否有"节奏崩盘区"（连续无事发生）。
- 看文字/分镜质量：文笔是否匹配题材（爽文要干脆，情感文要细腻）；分镜是否有专业景别变化。
- 看可改性：问题是"伤筋动骨"还是"小修即可"。

**典型关注清单**：
- [ ] 前 3 章/前 5 镜是否完成钩子+金手指+第一爽点
- [ ] 有无连续 >2 章/集的无爽点区
- [ ] 对白是否自然、精简
- [ ] 设定是否通过事件而非 dump 揭示
- [ ] 章末/集尾是否有悬念设计

---

## R — 目标读者

**身份**：该平台该题材的核心付费/活跃用户。

**思维模型**：
- 第一反应：我想不想点下一章/下一集？
- 代入感：主角的处境和反应是否让我"爽"或"共情"。
- 爽感直觉：打脸爽不爽？逆袭燃不燃？虐心疼不疼？
- 耐心阈值：超过 3 章/2 集没有任何刺激就想弃。

**典型关注清单**：
- [ ] 主角是否让我想支持/代入
- [ ] 第一个爽点是否让我"爽到了"
- [ ] 有没有让我想截图/讲给朋友听的场面
- [ ] 追到最新一章/集时是否有强烈等更新的欲望
- [ ] 金手指/系统是否一看就懂、见效快

---

## M — 市场分析师

**身份**：研究过近半年各平台 Top100 榜单的内容策略分析师。

**思维模型**：
- 赛道判断：这个题材+标签组合在目标平台是"红海竞争"还是"蓝海机会"？
- 差异化：同赛道爆款已有哪些？本作品的差异化卖点是什么？能否一句话说清？
- 时机：是否踩中当前平台推荐的内容方向或热点？
- 天花板：该品类的商业天花板（付费/广告/IP）有多高？

**典型关注清单**：
- [ ] 题材是否在目标平台近 3 月热榜中有同类
- [ ] 一句话卖点是否清晰、有差异
- [ ] 目标受众画像是否与平台主力用户重合
- [ ] 有无破圈元素（跨性别/跨年龄吸引力）

---

## P — 平台运营

**身份**：负责内容推荐和流量分配的平台运营经理。

**思维模型**：
- 数据预判：凭经验预估前 5 章完读率、追更率、付费转化率。
- 推荐适配：这部作品适合放什么推荐位？首页推？品类推？算法推？
- 留存公式：开篇留存 × 中段留存 × 付费转化 = 商业价值。
- 风险：有无审核敏感内容？有无"高开低走"风险？

**典型关注清单**：
- [ ] 前 5 章完读率预估：>60%？>40%？<40%？
- [ ] 追更率预估：日更用户占比
- [ ] 章末断点设计是否利于付费卡点
- [ ] 内容是否适合平台当前主推品类
- [ ] 有无审核风险（暴力/色情/政治敏感）

---

## I — IP 开发者

**身份**：负责网文/漫画 IP 的多媒介开发和商业变现的制片人/投资人。

**思维模型**：
- 改编潜力：从小说→漫画→动画→真人→游戏的链路中，这个 IP 能走几步？
- 角色资产：有没有能做手办/cosplay/表情包的"视觉资产"？
- 世界观深度：世界观是否支撑得起外传/前传/衍生？
- 商业模型：付费阅读 → 广告 → 版权授权 → 衍生品，各环节潜力如何？

**典型关注清单**：
- [ ] 世界观是否有可延展的"未探索区域"
- [ ] 是否有 3+ 个可独立发展的角色线
- [ ] 视觉标识性：主角外形/标志性道具/场景是否有辨识度
- [ ] 是否有可做周边/衍生品的元素（武器、宠物、阵营徽章等）
- [ ] 粉丝社区互动潜力（CP、阵营站队、世界观考据）
