# 爆款潜力评估 Skill

用**五种评估师视角** × **八个评估维度**的量化评分卡，快速判断一部小说或动态漫画的爆款潜力，并给出优先改进项。

**设计原则**：评分卡本身是结构化模板——人可手填、AI 可自动填；详细评分标准在 `references/` 中按需加载，不占常驻 token。

## 何时使用

- "帮我评估这部小说/动态漫能不能火"
- "从编辑/读者/市场角度打分"
- "这个大纲爆款潜力怎么样"
- "给我一份系统的评估报告"

---

## 一、五种评估师角色

| 代号 | 角色 | 关注焦点 | 权重维度 |
|------|------|----------|----------|
| E | 资深编辑 | 叙事技巧、结构完整度、文字/分镜质量 | 钩子力、节奏、人设 |
| R | 目标读者 | 代入感、爽感、追更/连播欲 | 爽点密度、钩子力、留存 |
| M | 市场分析师 | 赛道热度、差异化、竞品对比 | 市场契合、传播性 |
| P | 平台运营 | 完读/留存数据预判、推荐位适配 | 留存潜力、节奏、爽点密度 |
| I | IP 开发者 | 改编空间、多媒介延展、商业变现 | IP 延展性、人设、传播性 |

> **省 token 策略**：用户可指定 1–3 个角色做"聚焦评估"，不必每次全跑五个。默认：E + R + M。

---

## 二、八维评分卡（1–5 分制）

| # | 维度 | 一句话定义 | 小说适用 | 漫画适用 |
|---|------|-----------|---------|---------|
| D1 | 钩子力 | 前 3 章/前 5 镜能否留住人 | ✓ | ✓ |
| D2 | 爽点密度 | 每 N 章/集是否有可命名爽点 | ✓ | ✓ |
| D3 | 人设吸引力 | 主角标签清晰度+配角记忆点 | ✓ | ✓ |
| D4 | 节奏控制 | 张弛有度、无拖沓无跳跃 | ✓ | ✓ |
| D5 | 市场契合度 | 题材赛道热度 × 差异化 | ✓ | ✓ |
| D6 | 留存潜力 | 断章悬念、追更/连播动力 | ✓ | ✓ |
| D7 | 传播性 | 有无"可截图/可复述"的名场面 | ✓ | ✓ |
| D8 | IP 延展性 | 世界观/角色能否跨媒介 | ✓ | ✓ |

> 每维度 1–5 分标准见 `references/evaluation-rubrics.md`，仅在需要细化判断时读取。

## 三、工作流

### 步骤 1：确认评估对象与范围

收集以下信息（缺哪个问哪个）：

- **类型**：小说 / 动态漫画
- **评估材料**：大纲 / 前 N 章/集正文 / 完整作品
- **目标平台**：番茄/起点/七猫/B站/快看/抖音/通用
- **评估师**：全部五个 / 指定角色代号（如 E+R+M）

### 步骤 2：快速扫描（AI 或人工均可）

对材料做结构化提取，填入**素材摘要卡**：

```
【素材摘要卡】
题材/类型：
主角标签（3-5个）：
核心金手指/设定：
开篇钩子类型：
前3章/前5镜事件：
已识别爽点清单（章/集号+类型）：
结尾悬念方式：
```

> 此卡可由人手动填写后交给 AI 打分，省去 AI 阅读全文的 token。

### 步骤 3：分角色评分

每位评估师独立填写评分行，格式固定：

```
【评分卡 — {角色名}（{代号}）】
| 维度 | 分数 | 一句话依据 |
|------|------|-----------|
| D1 钩子力 | ?/5 | … |
| D2 爽点密度 | ?/5 | … |
| … | | |
| 总分 | ??/40 | |
关键短评（≤50字）：
```

**规则**：
- 每个"一句话依据"≤20 字，强制精简
- 仅对该角色权重维度给详细依据，其余可写"—"跳过
- 如需细化某维度的 1–5 分标准，读取 `references/evaluation-rubrics.md`

### 步骤 4：汇总与决策

输出**汇总表**：

```
【汇总评分】
| 维度 | E | R | M | P | I | 均分 |
|------|---|---|---|---|---|------|
| D1   |   |   |   |   |   |      |
| …    |   |   |   |   |   |      |
| 总均分 |  |   |   |   |   |     |

爆款潜力判定：
- ≥4.0 均分：高潜力，可重点投入
- 3.0–3.9：有潜力，需针对性优化
- <3.0：需大幅调整或换方向

角色间分歧最大的维度：{维度名}（最高{X}分 vs 最低{Y}分）→ 说明什么问题
```

### 步骤 5：改进优先级（Top 3）

按"提升空间 × 影响权重"排序，输出 3 条改进建议：

```
【改进优先级】
1. [维度] 现状→目标：具体动作（≤30字）
2. …
3. …
```

## 四、省 Token 用法指南

| 场景 | 做法 |
|------|------|
| 只需快速判断 | 跳过步骤 2，直接给材料让 AI 填评分卡 |
| 人工预处理 | 人填"素材摘要卡"，AI 只做步骤 3–5 |
| 聚焦评估 | 指定 1–2 个角色，只填对应行 |
| 对比评估 | 同一评分卡填两部作品，对比均分 |
| 纯人工使用 | 打印评分卡模板 + 读 references/ 中的评分标准，无需 AI |
