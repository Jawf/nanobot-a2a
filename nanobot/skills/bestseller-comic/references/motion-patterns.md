# 动态漫画动效与分镜节奏参考

本文件供 bestseller-comic 技能在设计分镜动态与节奏时用 `read_file` 读取。对应专业分镜师对“动效语言”的运用，便于在分镜表中写出可执行的动态建议。

---

## 一、常用动效类型与适用场景

| 动效 | 常见用法 | 节奏/情绪 |
|------|----------|-----------|
| 推镜（推进） | 从环境到人物、从全身到面部，强调情绪或关键信息 | 紧张、聚焦、揭秘 |
| 拉镜（拉远） | 从特写拉至全景，展现规模/孤独/结局感 | 收束、震撼、留白 |
| 摇镜 | 跟随动作、扫过场景、从 A 角色到 B 角色 | 连贯、引导视线 |
| 快切 | 连续多镜快速切换，同场景多角度或动作分解 | 打斗、紧张、节奏加快 |
| 闪白/闪黑 | 撞击、回忆切入、转折、震惊 | 冲击、转折、时间跳 |
| 震动 | 打击、爆炸、情绪爆发 | 力量感、冲击感 |
| 速度线/残影 | 快速移动、出拳、冲刺 | 动感、力量、速度 |
| 淡入/淡出 | 场景转换、时间流逝、情绪收尾 | 柔和过渡、抒情 |
| 定格 | 关键台词/关键表情停留 0.5–1 秒 | 强调、金句、记忆点 |

---

## 二、情绪与景别/动效搭配

- **燃/爆点**：中近景→特写 + 推镜或震动 + 可配合速度线/闪白。
- **虐/泪点**：特写（表情/手/信物）+ 淡入淡出或慢推，少快切。
- **悬疑**：中景/特写交替 + 慢推或定格，关键信息一镜强调。
- **打斗/追逐**：多快切 + 摇镜跟随 + 撞击时震动/闪白。
- **反转**：前一镜铺垫→下一镜特写或拉镜揭示 + 闪白或定格。

---

## 三、分镜节奏建议

- **紧张段**：单镜时长缩短，快切增多，动效（震动/闪白）密度提高。
- **抒情/过渡**：单镜可略长，多用淡入淡出、慢推拉，对白格可稍多。
- **高潮**：至少一镜大格或跨格，配合推镜/震动/定格，避免被快切“冲淡”。
- **结尾悬念**：最后一镜可定格或慢拉，配合旁白/金句，留白 0.5–1 秒再黑场或淡出。

---

## 四、分镜表“动态建议”栏写法示例

- “推镜至面部特写，0.5s”
- “快切：A 视角→B 视角→撞击，震动+闪白”
- “速度线+残影，出拳至命中，震动”
- “淡出至黑场，旁白收束”
- “定格 0.8s，后淡出”

便于后期与剪辑按表执行，同时保持节奏与情绪一致。
